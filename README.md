# Уведомления о билетах «Локомотива»

Настроено для ожидания домашних матчей **30 декабря 2026 — Ак Барс** и **6 января 2027 — Металлург**. Годы выбраны исходя из даты запроса; при необходимости измените подписи в скрипте и `watch_until` в конфигурации.

Источник: [официальный Telegram-канал клуба](https://t.me/hclokomotiv_official).

## Что делает

- Раз в минуту читает публичную страницу канала, без входа в ваш Telegram-аккаунт и без прав администратора канала.
- Пересылает текст билетных объявлений со ссылкой на оригинал. Проверяет все билетные объявления: клуб может объявить продажи на целую серию без названий соперников. Поэтому возможны уведомления о других матчах.
- Если в отдельной фразе о начале продаж однозначно указаны дата и время, сообщает их и напоминает за сутки, час, 10 минут и в момент старта. Все часы московские.
- Понимает, например: «Старт продаж 20 декабря в 10:00», «Продажи начнутся завтра в 12:00», «Начало продаж 20.12.2026 в 10:00».
- Если времени нет или текст неоднозначен, присылает оригинал без автоматических напоминаний. Дату матча не следует принимать за старт продаж. Разные этапы продаж, предложения со временем матча, дата и время на разных строках требуют проверки человеком.
- Сохраняет обработанные посты и напоминания в SQLite. При первом запуске проверяет историю за 30 дней, после перезапуска дочитывает новые посты. Изменения в постах на текущей странице тоже проверяются; старые напоминания изменённого поста отменяются.
- В личном чате `/start` включает подписку, `/stop` отключает её. Подписки и очередь доставки хранятся в `state.sqlite3`. Ошибки мониторинга и доставки записываются в журнал.
- Сам прекращает работу 7 января 2027 в 00:00 МСК.

## Запуск на Windows

Нужен Python 3.10 или новее. Распакуйте архив в постоянную папку, откройте в ней PowerShell.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
notepad config.json
```

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и создайте бота. Сохраните полученный токен в поле `bot_token` файла `config.json`. Токен никому не пересылайте.
2. Запустите скрипт:

```powershell
.\.venv\Scripts\python.exe loko_alert.py
```

3. Откройте своего бота и нажмите «Запустить» или отправьте `/start`. Дождитесь подтверждения подписки. Поделитесь ссылкой `https://t.me/имя_бота` с друзьями; каждый подписывается сам. Старые объявления, уже обработанные скриптом, повторно не рассылаются. Будущие напоминания из них придут действующим подписчикам.

`chat_id` необязателен. При обновлении он один раз добавляется к подписчикам, если уже указан. Бот должен работать без webhook и других программ, читающих его входящие обновления. Не запускайте две копии одновременно.

Окно должно оставаться открытым. Остановка: `Ctrl+C`. При повторном запуске используется сохранённое состояние. При аварии ровно между отправкой и сохранением возможно повторное уведомление.

## Обновление на Ubuntu

В папке работающего скрипта замените `loko_alert.py` файлом из нового архива. Сохраните `config.json` и `state.sqlite3`. Новые таблицы появятся автоматически. Если служба называется `loko-alert`, выполните `sudo systemctl restart loko-alert`, затем отправьте боту `/start` из двух личных чатов для проверки. Журнал: `sudo journalctl -u loko-alert -f`.

Дополнительные режимы:

```powershell
# Прочитать канал и показать объявления в консоли, ничего не отправляя и не сохраняя:
.\.venv\Scripts\python.exe loko_alert.py --dry-run
# Один проход с реальной отправкой:
.\.venv\Scripts\python.exe loko_alert.py --once
# Проверки логики без отправки сообщений:
.\.venv\Scripts\python.exe -m unittest -v
```

Для `--dry-run` токен не нужен; если `config.json` ещё не создан, используется пример конфигурации.

## Как оставить включённым

Для непрерывной работы нужен включённый компьютер без сна либо сервер. Скрипт сам по себе не включает компьютер. Если машина выключена, объявление и напоминание придут после запуска, а не вовремя. Несколько просроченных напоминаний одного поста объединяются в одно.

В Планировщике заданий Windows создайте задачу:

- Триггер: при входе в систему.
- Программа: полный путь к `.venv\Scripts\python.exe` внутри этой папки.
- Аргументы: полный путь к `loko_alert.py` в двойных кавычках.
- Рабочая папка: папка со скриптом.
- При сбое перезапускать через минуту; при уже работающей задаче не запускать второй экземпляр. Отключите ограничение длительности выполнения задачи.

База и конфигурация всегда читаются относительно файла скрипта, независимо от рабочей папки.

## Границы работы

Скрипт реагирует на опубликованные сообщения, предсказать ещё не объявленный старт продаж он не может. Если объявление вышло только в момент старта, предварительного предупреждения не будет. Напоминания ставятся только на ещё не прошедшие сроки.

Текст, написанный только на картинке, не распознаётся: OCR здесь нет. Короткое сообщение без слов «билеты», «продажи», «касса», «абонемент» или `ticket` тоже может не пройти фильтр. Закрепления и изменения старых постов вне текущей страницы отдельно не отслеживаются. За один проход история ограничена 100 страницами; при превышении скрипт сообщает об ошибке, а не молча пропускает историю. Удаление исходного поста не отменяет уже сохранённые напоминания. Новое отдельное сообщение о переносе приходит как уведомление, но автоматически не отменяет напоминания из другого поста.

Если нужно отменить старые напоминания, остановите скрипт и выполните команду ниже, затем запустите мониторинг снова. Число `12345` замените последним числом ссылки на старое объявление, например `https://t.me/hclokomotiv_official/12345`. При следующем редактировании исходного поста напоминания могут создаться заново.

```powershell
.\.venv\Scripts\python.exe loko_alert.py --cancel 12345
```

Публичная страница Telegram может стать недоступна или изменить разметку. Это не гарантированный канал доставки; включите также уведомления самого канала на телефоне. Скрипт не покупает билеты и не открывает платёжные страницы.
